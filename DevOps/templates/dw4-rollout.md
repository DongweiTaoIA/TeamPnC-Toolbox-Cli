# DW4 rollout - generated backlog template

Generated by `src/template.py` from the DW2 (501-572) and DW3/Honda (601-672) rollouts.

Those two rollouts ran the **same 54 numbered steps, matching 54 out of 54 with no gaps**. The sequence below renumbers that proven playbook to the 701-772 range for **DW4**.

Each row links the DW2 and DW3 tickets that already did the step, so whoever picks it up can read exactly how it was done last time before starting.

## How to use this

1. Review the step list - drop any step that does not apply to this OEM, and note the reason.
2. Create the work items using the generated titles.
3. On each new ticket, paste the **Reference** links into the description.
4. Keep the ordering. The phases below are sequential; steps within a phase can often run in parallel.

## Phases

- **Data upload** (12 steps) - Load and validate source data, table by table.
- **Transaction types** (19 steps) - Premium, cancellation, claims, cash and suspense handling.
- **Reports** (5 steps) - The DPR316x / DPR318x report family.
- **WebAPI** (5 steps) - Service layer endpoints.
- **UI** (10 steps) - Screens.
- **Close-out** (3 steps) - Scripts, regression testing and aging reports.
